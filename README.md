# 月之彼端

Vue 3 + Three.js / WebGL 的中文沉浸式月球体验。滚动依次经历轨道观察、月球纹理、近景下降和月面回望地球。

## 本地启动

```sh
npm install
npm run dev
```

## 构建与部署

```sh
npm run build
npm run preview
```

将 `dist/` 部署到静态托管服务。贴图与字体已本地化，运行不依赖第三方 CDN。请通过 HTTP 服务访问，不要直接双击 HTML。

## 交互

- 滚动驱动镜头，顶部按钮跳转章节。
- 太阳滑块改变光照与真实投影；支持方向键调节。
- 地形骨架按钮切换线框。
- 月面可进入纯净视野；Esc 退出。
- 氛围音默认关闭，由用户手动开启。它是合成配乐，并非月球实录。
- 支持手机布局、键盘焦点和系统减少动态效果偏好。

## 数据与真实精度

NASA Scientific Visualization Studio, CGI Moon Kit: https://svs.gsfc.nasa.gov/4720/

月球颜色贴图使用 2025 年更新的官方 4096 × 2048、16 位 TIFF 转换的 JPEG（仅做浏览器格式压缩）；源于 LROC 广角相机拼接；凹凸贴图源于 LOLA 高程。本网页并非原始科学数据浏览器：全球颜色贴图、原始 NAC 窄角相机影像、近景程序地形是三种不同内容，不可混淆。一米/像素或更优的说明来自 NASA 对 NAC 数据的描述，不表示本网页有全球一米级地形。

月面近景与岩石为确定性程序生成，地球位置和航程距离为艺术构图与示意，并不代表指定地点、时间或物理着陆轨迹。球面到近景采用连续镜头运动配合短段交叉溶解，不是全球地形瓦片流式加载。

NASA / IBM 合作关系没有得到核实，本项目不作相关声明。

地球纹理来自 Three.js 示例 `earth_atmos_2048.jpg`。中文标题字体为 Noto Serif SC 子集，许可证见 `public/fonts/LICENSE.txt`。

## 实现

`src/App.vue` 管理章节、进度、说明、光照滑块与声音。`src/scene.js` 管理两套三维场景、镜头、真实阴影和转场。`src/style.css` 定义响应式视觉。

无后端、无提交接口、无账号系统。纹理加载失败会显示恢复操作；不支持 WebGL 的设备显示明确提示。

## 代码阅读路线

1. `index.html` → `src/main.js`：提供挂载容器，加载全局样式并启动 Vue。
2. `src/App.vue`：先看顶部状态和生命周期，再看交互函数与四个章节模板。挂载时创建三维场景，卸载时释放场景和声音资源。
3. `src/scene.js`：按编号阅读渲染器、远景月球、近景月面、合成器和动画循环，文件末尾是供页面调用的控制接口。
4. `src/style.css`：按分区阅读基础样式、章节布局、状态栏、弹窗和响应式覆盖。文件末尾的同名规则继续覆盖前面的样式。

核心流程：滚动或点击章节按钮 → `sync()` 更新 `progress` → 页面更新章节、距离和进度条，同时调用 `scene.setProgress()` → `draw()` 平滑推进镜头 → 两个场景分别渲染到离屏纹理 → 合成器混合后输出到画布。

太阳滑块和线框按钮分别调用 `setSun()` 与 `setWireframe()`；声音通过 Web Audio 独立合成。近景高度函数 `height()` 同时用于地形、岩石落点和相机离地高度。

## 代码格式

使用项目内固定版本的 Prettier，规则见 `.prettierrc.json`：两空格缩进、单引号、分号、每行目标长度 100 字符。命令覆盖源码、入口 HTML、Vite 配置、项目配置和 SVG 图标，排除依赖、构建产物与二进制素材。

```sh
npm run format        # 统一格式
npm run format:check  # 检查格式，不修改文件
npm run build         # 验证生产构建
```

`scene.js` 内的 GLSL 着色器已手动展开；Prettier 不会自动格式化模板字符串内部的 GLSL。
